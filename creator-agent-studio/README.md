# 随行录

以项目为中心的移动记录应用。注册或登录后，可创建项目，通过文字、语音转写和照片记录事项；未完成事项按北京时间显示在时间线中，完成后自动隐藏。

## 功能

- 登录与注册
- 项目创建、编辑和项目内事项管理
- 项目说明语音转文字
- 项目内照片记录
- 北京时间时间线
- 事项完成与隐藏
- 个人资料、账号安全、个人信息和提醒设置
- PWA 清单、离线缓存和移动端启动动画

## 本地运行

运行 `npm run start:direct`，访问 `http://127.0.0.1:3210/`。

## 数据说明

当前版本使用浏览器本地存储。正式面向公众运营前，应接入服务端认证、数据库和对象存储。
